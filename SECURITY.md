# Security Policy

## Supported Versions

Only the latest released version of Smart Table receives security fixes.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for a security vulnerability.

Instead, report it privately via [GitHub's private vulnerability reporting](https://github.com/anvildevxyz/craft-smart-table/security/advisories/new), or email fabian.haefliger@zeix.com with:

- A description of the vulnerability and its potential impact.
- Steps to reproduce it (a minimal field configuration and request, where possible).
- The plugin version and Craft CMS version affected.

You should expect an initial response within a few business days. Once a fix is confirmed, it will be released as soon as possible and credited in `CHANGELOG.md`, unless you prefer to remain anonymous.
